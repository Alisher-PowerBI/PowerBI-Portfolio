# 💰 Finance Performance Dashboard

## 📊 Project Overview

This Power BI dashboard provides a comprehensive financial performance analysis for a fictional company. It helps business leaders monitor revenue, costs, profitability, budget performance, and sales trends through interactive visualizations.

![Dashboard](Dashboard.png)

---

## 📈 Key KPIs

- 💵 Total Revenue
- 💸 Total Cost
- 💰 Gross Profit
- 📊 Profit Margin
- 🎯 Budget Variance
- 📦 Units Sold

---

## 📊 Dashboard Features

- Revenue by Month
- Revenue by Region
- Gross Profit by Category
- Budget by Month
- Revenue by Product
- Top Customers by Revenue & Gross Profit
